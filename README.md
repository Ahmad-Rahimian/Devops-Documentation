# DevOps Documentation

This repository contains my personal notes and documentation for building and managing DevOps infrastructure. It includes detailed, hands-on guides for:

- Kubernetes setup and management
- Helm chart deployments
- Kafka & Zookeeper installation
- Docker usage and optimization
- CI/CD workflows and GitOps practices

## 🧰 Tools Covered

- Docker, Compose
- Kubernetes, Helm
- Kafka, ZooKeeper
- GitHub Actions, ArgoCD, Jenkins

## 🌐 Scope

Most guides are written with real-world production environments in mind, including cloud-native and self-hosted setups.
